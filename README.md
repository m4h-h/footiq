# FootIQ ⚽

Football analytics, scouting and player comparison platform.

## About

FootIQ is a football analytics platform designed to explore player
and team performance using real-world football data.

The project will combine full-stack development, databases,
data analysis and algorithms to provide tools for comparing
players, evaluating performance and identifying similar players.

## Planned Features

- Player profiles and statistics
- Team analytics
- Player comparison
- Player similarity algorithm
- Custom player ratings
- Scouting recommendations
- Data visualisations
- User accounts and personalised dashboards

## Tech Stack

- Frontend: React
- Backend: Python / FastAPI
- Database: PostgreSQL
- Data: Football statistics API
